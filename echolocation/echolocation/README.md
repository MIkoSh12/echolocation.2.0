# Echolocation (Fabric, Minecraft 26.3)
Клиентский мод: любой звук рядом создаёт расходящуюся волну.
- поверхности блоков на фронте волны подсвечиваются голубым (видно сквозь стены);
- мобы внутри волны подсвечиваются оранжевым боксом (видно сквозь стены).

Требуется: Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 26.3, Java 25.
Сборка: `gradle build` (Gradle 9.6.0) -> `build/libs/echolocation-1.0.0.jar`
Тест: `gradle runClient`
